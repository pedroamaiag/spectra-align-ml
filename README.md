# Spectra Align ML

Spectra Align ML is an academic project focused on applying machine learning techniques to Sentinel-2 satellite imagery.

The current goal is to study supervised learning approaches for transforming Sentinel-2 Level-1C data into representations closer to Level-2A surface reflectance products.

---

---

## Development

The project is being developed incrementally, starting with data acquisition, inspection, preprocessing, and visualization.

Machine learning models will be introduced only after the Sentinel-2 data pipeline is understood and validated.
