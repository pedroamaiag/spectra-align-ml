# Problem Definition

## Context

Atmospheric effects influence the spectral information recorded by optical Earth observation satellites. For quantitative remote sensing applications, these effects must be reduced so that the observed signal more closely represents the Earth's surface.

Sentinel-2 provides Level-1C products containing Top-of-Atmosphere (TOA) reflectance and Level-2A products containing atmospherically corrected Bottom-of-Atmosphere (BOA) surface reflectance.

This project focuses on Sentinel-2 imagery acquired over the Caatinga biome, with emphasis on areas located in the state of Ceará, Brazil.

## Problem

Traditional atmospheric correction methods rely on physical models and atmospheric parameters to transform TOA reflectance into surface reflectance.

Recent studies indicate that supervised deep learning models can learn an approximation of this transformation directly from paired satellite observations.

The problem investigated in this project is whether a supervised learning model can learn the mapping between Sentinel-2 Level-1C and Level-2A imagery for regions of the Caatinga biome in Ceará.

## Motivation

The Caatinga presents strong seasonal changes in vegetation, exposed soil, and surface reflectance, making it an interesting environment for evaluating atmospheric correction models.

A model trained and evaluated specifically on this region may help determine whether data-driven atmospheric correction methods can reproduce Level-2A-like reflectance under the environmental conditions found in the biome.

The study also allows the evaluation of the computational cost of a machine learning approach compared with the complexity of traditional atmospheric correction pipelines.

## General Objective

Develop and evaluate a supervised learning approach capable of transforming Sentinel-2 Level-1C imagery into an approximation of the corresponding Level-2A surface reflectance for areas of the Caatinga biome in Ceará.

## Scope

The project will:

- use Sentinel-2 Level-1C imagery as model input
- use corresponding Sentinel-2 Level-2A products as reference targets
- focus on selected regions of the Caatinga biome within Ceará
- evaluate the model using quantitative image and reflectance metrics
- consider computational cost during model evaluation

The Level-2A product will be treated as a practical reference generated by an established atmospheric correction process rather than as an exact measurement of physical ground-truth surface reflectance.
